# 뉴욕 Citi Bike EDA — 저지시티 공유자전거 이용 분석

새싹캠퍼스 데이터 리터러시 과정 실습. 2023년 1~3월 저지시티 Citi Bike 대여 기록 **13,696건**을 탐색적 데이터 분석(EDA)한 기록이다.

📊 **[분석 리포트 보기](https://sojung-yun404.github.io/sesac-dataliteracy/)**

---

## 결론

> **이 서비스는 레저가 아니라 통근 인프라다.**

- 이용의 **98.2%가 정기구독자**, 대여시간 **중앙값 5.2분**, 편도가 97.5%
- 이용량 1·2위 역(Grove St PATH, Exchange Place)이 **맨해튼행 PATH 환승역**
- 주요 이동 경로 7개 중 5개가 **주거지 → 환승역**
- 그 결과 Grove St PATH에 **79일간 544대분이 순유입** → 재배치 필요

일회 이용자(1.8%)는 주말·공원 중심의 완전히 다른 패턴을 보이지만, **절대 규모는 전체의 6%**에 그친다.

## 분석 순서

| 단계 | 스크립트 | 한 일 |
|---|---|---|
| 1 | `eda_01_outliers.py` | 이상치·정합성 점검, 정비소 이동 기록 발견 |
| 2 | `eda_02_distribution.py` | 단변량 분포 — 대여시간 왜도 35.9 확인 |
| 3 | `eda_03_bivariate.py` | 이변량 관계 — 평균의 함정, 심슨의 역설, 교란변수 |
| 4 | `eda_04_answers.py` | 워크북 문제 1~4번 답안 |
| 5 | `eda_05_deepdive.py` | 주말 정기구독자 정체, 연령대 교차 |
| 6 | `eda_06_profile.py` | 두 사용자 그룹 종합 프로파일 |
| 7 | `eda_07_correction.py` | 비율을 규모로 오독한 것 정정 |

`eda_common.py` — 공통 로더와 클리닝(요일 접두사 제거, 정비소 기록 제외)
`report_figs.py` — 리포트용 차트 4장
`inline_figs.py` — 이미지를 base64로 리포트 HTML에 삽입

## 리포트 빌드

`report_src.html`이 원본이고, 이미지 자리에 `FIG:파일명.png` 플레이스홀더가 들어 있다.
아래 명령이 이미지를 base64로 심어 `docs/index.html`을 만든다 — 외부 파일 없이 혼자 열리는 한 장짜리 HTML이다.

```bash
.venv/bin/python inline_figs.py report_src.html docs/index.html --standalone
```

차트를 다시 그렸으면 `report_figs.py`를 먼저 실행한 뒤 이 명령을 돌리면 리포트가 갱신된다.

## 이 분석에서 걸러낸 함정

**평균으로 줄 세우면 순위가 바뀐다**
연령대별 대여시간을 평균으로 보면 35-44세가 2위, 중앙값으로 보면 5위다. 대여시간은 왜도 35.9의 극단적 우편향 분포라 평균이 소수의 장시간 대여에 끌려간다.

**IQR 이상치 제거를 그대로 적용하면 안 된다**
IQR 상한(16분) 초과가 1,064건(7.8%)인데, 16분 자전거 타는 것은 이상한 일이 아니다. 로그 변환하면 왜도가 1.06으로 떨어진다 — 원래 로그정규 분포다.

**결측이 0건이어도 결측이 없는 게 아니다**
일회 이용자 250건 중 **248건이 1986년생(37세)**으로, 전체 데이터의 최빈값이다. 결측을 최빈값으로 일괄 대체한 흔적이라 `isna()`에는 잡히지 않는다. 이 오염이 35-44세 그룹의 평균을 8.8분 → 7.5분만큼 부풀리고 있었다.

**상관을 인과로 착각하지 않는다**
기온과 대여건수의 상관 r=0.112는 날짜 추세가 만든 착시다. 추세를 통제하면 −0.088로 사라진다. 평일(+0.239)과 주말(−0.321)로 나누면 방향까지 반대다.

**조건부확률의 방향을 뒤집지 않는다**
`P(주말 | 일회이용자) = 44.8%`와 `P(일회이용자 | 주말) = 4.2%`는 다른 값이다. 일회 이용자는 주말에 몰리지만, **주말 이용자의 96%는 여전히 정기구독자**다.

**비율 막대를 규모로 읽지 않는다**
Liberty Light Rail은 일회 이용자 비율 11.2%로 1위지만, 241건 중 214건(88.8%)이 정기구독자다. 50건 이상인 모든 역에서 정기구독자 비율은 88.8% 아래로 내려가지 않는다 — **저지시티에 "관광형 역"은 없다.**

## 실행 방법

원본 엑셀 파일은 강의 자료라 저장소에 포함하지 않았다. `1.2 EDA_뉴욕 따릉이_Level2_문제 .xlsx`를 프로젝트 폴더에 두고 실행한다.

```bash
uv venv .venv --python 3.12
uv pip install --python .venv pandas openpyxl matplotlib pillow

.venv/bin/python eda_01_outliers.py      # 이상치 점검
.venv/bin/python eda_02_distribution.py  # 분포 → fig_02_distribution.png
.venv/bin/python eda_03_bivariate.py     # 이변량 → fig_03_bivariate.png
.venv/bin/python eda_04_answers.py       # 답안 → fig_04_answers.png
.venv/bin/python eda_05_deepdive.py      # 심화 → fig_05_deepdive.png
.venv/bin/python eda_06_profile.py       # 프로파일 → fig_06_profile.png
.venv/bin/python eda_07_correction.py    # 정정 → fig_07_correction.png
.venv/bin/python report_figs.py          # 리포트용 차트 4장 → rf_*.png
```

한글 폰트는 macOS 기본 `Apple SD Gothic Neo`를 쓴다. 다른 OS에서는 `eda_common.py`의 `font.family`를 바꿔야 한다.
